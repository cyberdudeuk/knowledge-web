# The Web — one page

**What it is.** A personal prototype — one self-contained web page, no install — that turns a body of work into something you can walk through: what exists, how it connects, and what's still missing. Six real bodies of work are loaded into it already, including a real 499-asset government data register.

**Why I'm showing you.** Not for sign-off, not to sell it. I think parts of this already overlap with what you're working on, and you'll spot the overlap — or the gap — faster than I can explain it.

**What it does that's different.** Every connection you see is generated live from the real data, not drawn by hand. And it says out loud what *doesn't* fit yet, instead of quietly leaving it out. That honesty is the actual point of the thing.

**Try it — 2 minutes.**
1. Open `the-web.html` in any browser.
2. Click **Tours** → **"For colleagues — where does this touch your work?"**
3. It drives itself. Six stops, narrated.

**If it won't run** (locked-down laptop, no local file access): use the slide deck instead — `The-Web-colleague-deck.pdf`. Same content, same real screenshots, no install needed either way.

**What I want from you.** One honest answer: does anything here connect to what you're doing? Or is there a gap you can see that I can't? Either is useful — that's the whole ask.
