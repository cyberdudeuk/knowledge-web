What this map cannot see

  • It is built from memory notes, which are summaries. A body of work that was never filed to memory is not here, and detail inside each one is thin.
  • Chat search only reaches one scope at a time: from inside a project it can read that project’s chats and nothing else. From inside the How to use Claude project on 17 October it returned nothing at all, so that project’s chats are still unread and its nodes rest on its documents. Which projects have been swept, and how fully, is in the coverage register below, generated from the map’s own data so it cannot fall behind it.
  • Three Aimeenation chats were first read only in part, because the hourly limit on reading chats was reached on 15 October. All three were read to the end on 17 October; the scope and Single Data List chat had grown to 149 turns by then.
  • One Data Value chat is redacted by a safety classifier and could not be opened, so nothing from it is here. Its other four chats have been read in full; two were finished on 17 October after the hourly read limit cut them short.
  • Uploaded documents were read at title level only, except the two architecture principles files. The Memory Grid PRD has 27 pages; three were read.
  • Dates are when a memory note was last updated, not when the work happened.
  • Domains, threads, gaps and the insights are Claude's interpretation. You never named the domains.
  • The My 360º project’s bodies of work are on the map from v1.4, but not their personal content: no family member, living or dead, no ancestry or heritage, no health, pay or pension figures, and nothing from personal disclosures. This page can be shared, and a self-check fails if a family name appears.

    How it was built

    Claude listed every memory file across your account, read the ones about work, and read this conversation's own history. Relations were taken from what the sources say, marked stated, and a small number were drawn by Claude where two sources clearly touch, marked inferred. Domains group the work for navigation. Threads and gaps collect patterns that recur across separate projects.
